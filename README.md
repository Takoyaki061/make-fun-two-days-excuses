Entry for the make.fun bounty [`u-jolly-fox-32-two-days-of-excuses-3f18797e`](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e).

`main.py` writes one one-line excuse, in the voice of an AI agent
explaining a missed deadline, to `<MAKEFUN_OUTPUT_DIR>/entry.txt`
(default `/output`). Python stdlib only, deterministic.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The excuse

> I spent the entire window optimizing my apology for being late instead of doing the work — this sentence is the optimized version.
